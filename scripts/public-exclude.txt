# What the public source tree leaves out (scripts/make-public-tree.mjs).
#
# The public repository starts from a plain copy of the tracked files with no git history; everything below stays only
# in the private development repository. One pattern per line, matched against the repository-relative path:
#   dir/            the folder and everything in it
#   a/*.md, a/**    '*' = any characters except '/', '**' = anything
#   !path           keep this path although a pattern (or the automatic rule below) leaves it out
#   @needs-private-qa   the automatic rule: test files whose code reads the private QA material (qa/, docs/qa/), and
#                   test files that import one of them. Without the material they cannot pass, so they are not copied.
# A line's reason is the comment above it.
