运行被拦截时

下载时：如果浏览器提示该文件“通常不会被下载”而拦截，请在下载列表中点开文件旁的 … 菜单，选择保留（Chrome 中为继续）。这是新应用下载量还少时会出现的警告。

运行时：当前版本尚未代码签名，SmartScreen 可能会拦截。如果文件来自本页且校验值一致：

安装包已代码签名。若仍出现 SmartScreen 警告：

  1. 点击更多信息。
  2. 确认应用名称是 Omniweave。
  3. 点击仍要运行。

如果文件来自其他地方，请不要运行。

更新

自动更新正在准备中。在此之前：

  1. 从本页下载新的安装包。
  2. 直接运行覆盖安装，工作文件 (.omw) 不受影响。

便携版只需换成新的 exe。

安装版和便携版都会自动检查新版本。下载后先校验，再询问你，确认后才更新。Store 版由 Store 负责更新。

便携版会核对新 exe 的大小、SHA-256 和签名，然后在原位置替换自身。无法写入所在文件夹时，会打开本页。

校验下载文件 (SHA-256)

每个版本都附带记录所有文件 SHA-256 值的 SHA256SUMS.txt。在本机算出的值与之完全一致，就说明文件在下载途中没有被改动。

在下载文件夹中运行
Get-FileHash .\Omniweave_0.1.0_x64-setup.exe -Algorithm SHA256
# 将输出的 Hash 与 SHA256SUMS.txt 中同名文件那一行比较（不区分大小写）
终端 · 在下载文件夹中
shasum -a 256 -c SHA256SUMS.txt --ignore-missing
终端 · 在下载文件夹中
sha256sum -c SHA256SUMS.txt --ignore-missing

在 macOS 和 Linux 上，把 SHA256SUMS.txt 放在下载的文件旁边再运行，一致的文件会显示 OK。
