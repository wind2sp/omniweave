更新

自动更新正在准备中。计划加入安装版，在此之前请这样更新：

  1. 从本页面下载新版本的安装程序。
  2. 直接运行，覆盖安装。你的工作文件 (.omw) 不会受影响。

便携版只需换成新的 exe 即可。

安装版和便携版都会自动检查新版本。有新版本时应用会先下载并校验，再提示你，确认后即更新。Microsoft Store 版本由应用商店更新。

便携版会在校验所下载 exe 的大小、SHA-256 和签名后，以相同文件夹、相同文件名替换自身。若文件夹不可写入，则打开本页面。

校验下载的文件 (SHA-256)

每个版本都会附带 SHA256SUMS.txt，其中列出所有文件的 SHA-256 值。如果你在本机计算出的值与其中的值完全一致，说明文件在下载过程中没有被篡改。

在下载文件夹中运行
Get-FileHash .\Omniweave_0.1.0_x64-setup.exe -Algorithm SHA256
# 将输出的 Hash 与 SHA256SUMS.txt 中同一文件那一行对比（不区分大小写）
终端 · 在下载文件夹中
shasum -a 256 -c SHA256SUMS.txt --ignore-missing
终端 · 在下载文件夹中
sha256sum -c SHA256SUMS.txt --ignore-missing

在 macOS 和 Linux 上，把 SHA256SUMS.txt 放在下载文件旁边再运行命令，校验一致的文件会显示 OK。
