If you see “Windows protected your PC”

When downloading: if Edge or Chrome says the file “isn’t commonly downloaded”, open the download list, choose … next to the file and pick Keep (Chrome: Keep or Download anyway). The warning appears because the app is new and has few downloads yet.

Current builds are not code-signed yet, so Microsoft Defender SmartScreen may block the first launch. If you downloaded the file from this page (GitHub Releases) and the checksum below matches:

The installer is code-signed. If SmartScreen still shows a warning, you can run it like this:

  1. Click More info in the warning.
  2. Check that the app name is Omniweave.
  3. Click Run anyway.

If you got the file from anywhere else, don't run it.

Updates

Automatic updates are coming. They're planned for the installer; until then:

  1. Download the new installer from this page.
  2. Run it to install over the old version. Your work files (.omw) are left untouched.

For the portable build, just replace the exe with the new one.

The installer and the portable build check for new versions on their own. When one is available, the app downloads and verifies it, lets you know, and updates once you confirm. The Microsoft Store version is updated by the Store.

The portable build replaces its own exe in place (same name and folder) after checking its size, SHA-256 and signature. If its folder is read-only, it opens this page instead.

Verify your download (SHA-256)

Every release includes SHA256SUMS.txt, which lists the SHA-256 hash of each file. If the value you compute matches it character for character, the file wasn't altered on the way to you.

Run in your download folder
Get-FileHash .\Omniweave_0.1.0_x64-setup.exe -Algorithm SHA256
# Compare the Hash with the same file's line in SHA256SUMS.txt (case doesn't matter)
Terminal · in your download folder
shasum -a 256 -c SHA256SUMS.txt --ignore-missing
Terminal · in your download folder
sha256sum -c SHA256SUMS.txt --ignore-missing

On macOS and Linux, put SHA256SUMS.txt next to the downloaded file and run the command — matching files are reported as OK.
