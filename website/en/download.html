If Windows blocks it

When downloading: if your browser says the file “isn't commonly downloaded”, open the … menu next to it in the downloads list and choose Keep (in Chrome, Keep anyway). New apps get this warning until more people have downloaded them.

When running: this build isn't code-signed yet, so SmartScreen may stop it. If you got it from this page and the checksum matches:

The installer is code-signed. If SmartScreen still warns you:

  1. Click More info.
  2. Check that the app name is Omniweave.
  3. Click Run anyway.

If you got the file anywhere else, don't run it.

Updates

Automatic updates are on the way. Until then:

  1. Download the new installer from this page.
  2. Run it to install over the old version. Your .omw files stay as they are.

For the portable app, just replace the exe.

Both the installer and the portable app check for new versions on their own. The download is verified first, then you're asked before anything is updated. The Store version is updated by the Store.

The portable app checks the size, SHA-256 and signature of the new exe, then replaces itself in place. If it can't write to its folder, it opens this page instead.

Verify your download (SHA-256)

Each release includes SHA256SUMS.txt with the SHA-256 of every file. If the value you compute matches exactly, the file wasn't altered on the way.

Run in the download folder
Get-FileHash .\Omniweave_0.1.0_x64-setup.exe -Algorithm SHA256
# Compare Hash with the line for the same file in SHA256SUMS.txt (case doesn't matter)
Terminal · in the download folder
shasum -a 256 -c SHA256SUMS.txt --ignore-missing
Terminal · in the download folder
sha256sum -c SHA256SUMS.txt --ignore-missing

On macOS and Linux, put SHA256SUMS.txt next to the downloaded files and run the command; matching files show OK.
