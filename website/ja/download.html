Omniweave をダウンロード

無料 · オープンソース（GPL-3.0）· バージョン 0.1.0 · 公開

近日公開

最初のリリース v0.1.0 を準備しています。

公開準備中です。最初のリリースが出たら、このページのボタンからすぐにダウンロードできます。それまでは、ソースから直接実行できます（リポジトリ公開後）。

プラットフォーム別のファイル

すべてのファイルは GitHub Releases から配布します。どのプラットフォームもファイルひとつでインストール・実行できます。

Windows 10 · 11

このパソコン
  • インストーラー版 おすすめOmniweave_0.1.0_x64-setup.exe

    約17 MB。スタートメニュー登録、.omwファイルの関連付け、管理者権限なしで現在のユーザーにインストール。

    近日公開
  • ポータブル版Omniweave_0.1.0_x64-portable.exe

    インストール不要の単体 exe。ファイルの関連付けやスタートメニューへの登録は行いません。

    近日公開

ブラウザー（ソースから）

インストーラーなしでブラウザー上で動かします。Node.js 18 以上が必要です。

インストールせずに今すぐ試す ブラウザー内だけで動作し、ファイルをサーバーに送りません。

ターミナル
git clone https://github.com/wind2sp/omniweave.git
cd omniweave
npm i
npm run dev

リポジトリは公開準備中です。公開されれば、上のコマンドがそのまま使えます。

「Windows によって PC が保護されました」と表示されたら

ダウンロード時: Edge や Chrome が「一般的にダウンロードされていません」と表示した場合は、ダウンロード一覧でファイルの … メニューから 保存(Chrome は 保存 または 続行)を選んでください。新しいアプリでダウンロード数がまだ少ないために表示される警告です。

現在のビルドはまだコード署名されていないため、Microsoft Defender SmartScreen が初回起動をブロックすることがあります。このページ（GitHub Releases）から入手したファイルで、下のチェックサムが一致していれば：

インストーラーはコード署名済みです。それでも SmartScreen の警告が出る場合は、次の手順で実行できます。

  1. 警告画面の詳細情報をクリックします。
  2. アプリ名が Omniweave であることを確認します。
  3. 実行をクリックします。

入手元がはっきりしないファイルは実行しないでください。

アップデート

自動アップデートは準備中です。インストーラー版に搭載する予定で、それまでは次の方法で更新してください：

  1. このページから新しいバージョンのインストーラーをダウンロードします。
  2. そのまま実行して上書きインストールします。作業ファイル（.omw）には影響しません。

ポータブル版は、新しい exe に置き換えるだけです。

インストーラー版とポータブル版は新しいバージョンを自動で確認します。新版があればアプリが受け取って検査したうえで知らせ、確認すると更新します。Microsoft Store 版はストアが更新します。

ポータブル版は受け取った exe のサイズ・SHA-256・署名を確認したうえで、同じフォルダー・同じ名前で自分自身を置き換えます。フォルダーに書き込めない場合はこのページを開きます。

ダウンロードしたファイルの確認（SHA-256）

リリースごとに、全ファイルの SHA-256 値を記載した SHA256SUMS.txtも公開しています。手元で計算した値がそのファイルの値と1文字残らず一致すれば、ダウンロード中に改ざんされていないファイルです。

ダウンロードしたフォルダーで実行
Get-FileHash .\Omniweave_0.1.0_x64-setup.exe -Algorithm SHA256
# 表示された Hash を SHA256SUMS.txt の同じファイルの行と比べます（大文字・小文字は区別しません）
ターミナル · ダウンロードしたフォルダーで
shasum -a 256 -c SHA256SUMS.txt --ignore-missing
ターミナル · ダウンロードしたフォルダーで
sha256sum -c SHA256SUMS.txt --ignore-missing

macOS・Linux では、ダウンロードしたファイルと同じ場所に SHA256SUMS.txt を置いて実行すると、一致したファイルに OK と表示されます。
