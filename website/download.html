곧 공개

첫 릴리스(v0.1.0)를 준비하고 있습니다.

공개 준비 중입니다. 첫 릴리스가 나오면 이 페이지의 버튼이 바로 동작합니다. 그 전에는 소스에서 직접 실행할 수 있습니다(저장소 공개 후).

플랫폼별 파일

모든 파일은 GitHub Releases에서 받습니다. 각 플랫폼은 파일 하나로 설치·실행됩니다.

    곧 공개

    곧 공개

웹 브라우저 (소스에서)

설치 파일 없이 브라우저에서 실행합니다. Node.js 18 이상이 필요합니다.

설치 없이 지금 써 보기 브라우저 안에서만 동작하며 파일을 서버로 보내지 않습니다.

터미널
git clone https://github.com/wind2sp/omniweave.git
cd omniweave
npm i
npm run dev

저장소는 공개 준비 중입니다. 공개되면 위 명령이 바로 동작합니다.

모든 릴리스와 변경 내역: GitHub Releases 페이지첫 릴리스 공개 후 링크가 열립니다.

“Windows의 PC 보호” 창이 뜨면

지금 빌드는 코드 서명 전이라 Microsoft Defender SmartScreen이 처음 실행을 막을 수 있습니다. 파일이 이 페이지(GitHub Releases)에서 받은 것이고 아래 체크섬이 맞는다면:

설치 파일은 코드 서명되어 있습니다. 그래도 SmartScreen 경고가 보이면 아래 순서로 실행할 수 있습니다.

  1. 경고 창에서 추가 정보를 누릅니다.
  2. 앱 이름이 Omniweave인지 확인합니다.
  3. 실행을 누릅니다.

출처가 불분명한 곳에서 받은 파일이라면 실행하지 마세요.

업데이트

자동 업데이트는 준비 중입니다. 설치본에 넣을 예정이며, 그 전까지는:

  1. 이 페이지에서 새 버전 설치본을 받습니다.
  2. 그대로 실행해 덮어 설치합니다. 작업 파일(.omw)은 건드리지 않습니다.

포터블은 새 exe로 바꿔 쓰면 됩니다.

설치본과 포터블 모두 새 버전을 스스로 확인합니다. 새 버전이 있으면 앱이 받아서 검사한 뒤 알려 주고, 확인을 누르면 업데이트합니다. Microsoft Store 판은 Store가 업데이트합니다.

포터블은 받은 exe의 크기·SHA-256·서명을 확인한 뒤 같은 폴더·같은 이름으로 스스로 바꿉니다. 폴더에 쓸 수 없으면 이 페이지를 엽니다.

받은 파일 확인 (SHA-256)

릴리스마다 모든 파일의 SHA-256 값을 적은 SHA256SUMS.txt를 함께 올립니다. 내 PC에서 계산한 값이 그 파일의 값과 한 글자도 빠짐없이 같으면 받는 도중 바뀌지 않은 파일입니다.

받은 폴더에서 실행
Get-FileHash .\Omniweave_0.1.0_x64-setup.exe -Algorithm SHA256
# 출력된 Hash 값을 SHA256SUMS.txt의 같은 파일 줄과 비교 (대소문자 무관)
터미널 · 받은 폴더에서
shasum -a 256 -c SHA256SUMS.txt --ignore-missing
터미널 · 받은 폴더에서
sha256sum -c SHA256SUMS.txt --ignore-missing

macOS·Linux 명령은 받은 파일 옆에 SHA256SUMS.txt를 두고 실행하면, 맞는 파일에 OK가 표시됩니다.
