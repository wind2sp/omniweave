한국어

Omniweave는 개인정보를 수집하지 않습니다. 계정·로그인이 없고, 사용 통계·분석·광고·오류 보고를 보내지 않으며, 파일을 서버에 올리지 않습니다. 열고 고치고 저장하는 모든 일은 사용자의 PC 안에서 이루어집니다.

앱이 인터넷을 쓰는 경우 (이것뿐입니다)

  • 업데이트 확인(GitHub에서 받은 설치본·포터블판): 앱을 켠 뒤 약 4초 뒤와 이후 6시간마다 https://github.com/wind2sp/omniweave/releases/latest/download/latest.json을 읽어 새 버전이 있는지 확인합니다. 도움말 › 업데이트 확인을 누를 때도 같습니다. 이 요청에는 문서 내용이나 개인정보가 들어가지 않습니다. 요청을 받는 GitHub는 일반 웹 요청처럼 IP 주소 등을 기록할 수 있으며, 이는 GitHub의 개인정보 처리방침을 따릅니다.
  • 업데이트 내려받기(설치본·포터블판): 새 버전이 있으면 GitHub에서 설치 파일(설치본) 또는 새 exe(포터블판)를 받아 서명(포터블판은 크기·SHA-256도)을 확인한 뒤, 확인을 누르면 설치하거나 같은 자리의 exe를 바꿉니다.
  • 릴리스 페이지 열기(포터블판): 포터블판이 놓인 폴더에 쓸 수 없거나 받은 파일 검사가 실패하면, 알림을 누를 때 기본 웹 브라우저로 GitHub 릴리스 페이지를 엽니다.
  • Microsoft Store 판은 업데이트를 Store가 하므로 위의 업데이트 확인도 하지 않습니다.

인터넷을 쓰지 않는 기능

  • AI 업스케일·배경 지우기·글자 인식(OCR) 모델은 앱 안에 들어 있고 이 PC에서만 실행됩니다. 모델을 따로 내려받지 않고, 이미지를 밖으로 보내지 않습니다.
  • 맞춤법 검사는 Windows에 들어 있는 맞춤법 검사 기능을 씁니다.
  • 글꼴·PDF 자원은 앱 안의 파일을 읽습니다.

PC에 남는 것

  • 설정, 최근 파일 목록, 비정상 종료에 대비한 자동 저장 기록은 사용자 PC의 앱 데이터 폴더에만 저장됩니다(Store 판은 앱을 제거하면 함께 지워집니다).
  • 업데이트 확인 기록 %TEMP%\omniweave-update.log(버전과 확인 결과만)이 PC에 남습니다. 어디에도 보내지 않습니다.

그 밖에

화면은 Windows의 WebView2(Microsoft Edge 엔진)로 그립니다. WebView2 자체의 동작은 Microsoft의 개인정보 처리방침을 따릅니다. 이 방침이 바뀌면 이 페이지와 저장소의 변경 기록에 알립니다. 문의: GitHub Issues, wind2sp@9rowpar.com

English

Omniweave collects no personal data. There is no account or sign-in; it sends no usage statistics, analytics, advertising or crash reports, and never uploads your files. Opening, editing and saving all happen on your PC.

When the app uses the internet (only these)

  • Update check (installer and portable builds from GitHub): about 4 seconds after start and every 6 hours after that, the app reads https://github.com/wind2sp/omniweave/releases/latest/download/latest.json to see whether a new version exists — also when you choose Help › Check for updates. The request contains no document content or personal data. GitHub, which answers it, may log the IP address like for any web request, under GitHub's privacy statement.
  • Update download (installer and portable build): when there is a new version, the installer (or, for the portable build, the new exe) is downloaded from GitHub and its signature is verified (for the portable build also its size and SHA-256); once you confirm, it is installed or the exe is replaced in place.
  • Opening the release page (portable build): if the portable build's folder is not writable or the downloaded file fails its checks, clicking the notice opens the GitHub release page in your default browser.
  • The Microsoft Store version is updated by the Store and does not perform the update check above.

Features that do not use the internet

  • The AI upscaling, background removal and text recognition (OCR) models are inside the app and run on your PC only. No model is downloaded and no image is sent anywhere.
  • Spell checking uses the spell checker built into Windows.
  • Fonts and PDF resources are read from files inside the app.

What stays on your PC

  • Settings, the recent-files list and the autosave journal (for recovery after a crash) are stored only in the app-data folder on your PC (the Store version removes them when the app is uninstalled).
  • An update log, %TEMP%\omniweave-update.log (versions and check results only), stays on your PC and is never sent.

Other

The window is drawn by Windows' WebView2 (the Microsoft Edge engine); WebView2 itself follows Microsoft's privacy statement. Changes to this policy are announced on this page and in the repository's change log. Contact: GitHub Issues, wind2sp@9rowpar.com

日本語

Omniweave は個人情報を収集しません。アカウントやサインインはなく、利用統計・分析・広告・エラー報告を送信せず、ファイルをサーバーにアップロードしません。開く・編集する・保存する作業はすべてお使いの PC 内で行われます。

アプリがインターネットを使う場合(これだけです)

  • 更新の確認(GitHub から入手したインストーラー版・ポータブル版): 起動の約 4 秒後と、その後 6 時間ごとに https://github.com/wind2sp/omniweave/releases/latest/download/latest.json を読み、新しいバージョンがあるか確認します。ヘルプ › 更新の確認を選んだときも同じです。この要求に文書の内容や個人情報は含まれません。要求を受ける GitHub は一般的なウェブ要求と同様に IP アドレスなどを記録することがあり、GitHub のプライバシーポリシーに従います。
  • 更新のダウンロード(インストーラー版・ポータブル版): 新しいバージョンがあれば GitHub からインストーラー(ポータブル版は新しい exe)を受け取り、署名(ポータブル版はサイズ・SHA-256 も)を確認し、確認を押すとインストールまたは同じ場所の exe を置き換えます。
  • リリースページを開く(ポータブル版): フォルダーに書き込めないときや受け取ったファイルの検査に失敗したときは、通知を押すと既定のブラウザーで GitHub のリリースページを開きます。
  • Microsoft Store 版はストアが更新するため、上記の更新確認も行いません。

インターネットを使わない機能

  • AI アップスケール・背景削除・文字認識(OCR)のモデルはアプリに含まれ、この PC だけで動きます。モデルを別途ダウンロードせず、画像を外部に送りません。
  • スペルチェックは Windows に組み込まれた機能を使います。

PC に残るもの

  • 設定、最近使ったファイル、異常終了に備えた自動保存の記録は PC のアプリデータフォルダーにのみ保存されます(Store 版はアンインストール時に削除されます)。
  • 更新確認の記録 %TEMP%\omniweave-update.log(バージョンと確認結果のみ)が PC に残り、どこにも送信されません。

画面は Windows の WebView2(Microsoft Edge エンジン)で描画され、WebView2 自体の動作は Microsoft のプライバシーに関する声明に従います。お問い合わせ: GitHub Issues、wind2sp@9rowpar.com

简体中文

Omniweave 不收集个人信息。没有账户或登录,不发送使用统计、分析、广告或错误报告,也不会把文件上传到服务器。打开、编辑和保存都在您的电脑上完成。

应用使用互联网的情况(仅限以下几项)

  • 检查更新(从 GitHub 获取的安装版和便携版):启动约 4 秒后以及之后每 6 小时,读取 https://github.com/wind2sp/omniweave/releases/latest/download/latest.json 以确认是否有新版本;选择 帮助 › 检查更新 时也一样。该请求不包含文档内容或个人信息。接收请求的 GitHub 可能像处理一般网页请求一样记录 IP 地址等,适用 GitHub 的隐私声明。
  • 下载更新(安装版和便携版):有新版本时从 GitHub 下载安装文件(便携版为新的 exe),验证签名(便携版还验证大小和 SHA-256),确认后安装或在原位置替换 exe。
  • 打开发布页面(便携版):若便携版所在文件夹不可写入或下载文件校验失败,点击提示时用默认浏览器打开 GitHub 发布页面。
  • Microsoft Store 版本由应用商店更新,不进行上述更新检查。

不使用互联网的功能

  • AI 放大、去除背景和文字识别(OCR)模型内置在应用中,只在本机运行;不另行下载模型,也不向外发送图像。
  • 拼写检查使用 Windows 自带的拼写检查功能。

留在电脑上的内容

  • 设置、最近文件列表以及为异常退出准备的自动保存记录只保存在电脑的应用数据文件夹中(Store 版本在卸载时一并删除)。
  • 更新检查记录 %TEMP%\omniweave-update.log(仅版本和检查结果)留在电脑上,不会发送到任何地方。

界面由 Windows 的 WebView2(Microsoft Edge 引擎)绘制,WebView2 本身适用 Microsoft 的隐私声明。联系方式:GitHub Issues,wind2sp@9rowpar.com
