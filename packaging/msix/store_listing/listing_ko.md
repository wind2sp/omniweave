## 제품 이름
Omniweave

## 간단한 설명 (Short description)
이미지, 벡터, PDF, DOCX·HWPX 문서, 슬라이드, 표, DWG·DXF 도면을 한 캔버스에서 열고 고치는 로컬 편집기입니다. 파일을 서버에 올리지 않고, 고치지 않은 부분은 원본 그대로 저장하는 것을 원칙으로 합니다. 무료 오픈소스입니다.

## 설명 (Description)
Omniweave(오메)는 여러 프로그램을 오가며 하던 일을 한 화면에 모은 편집기입니다. 문서의 그림을 고치고, PDF에 글을 더하고, 발표 자료로 옮기는 일을 같은 캔버스에서 합니다.

모든 개체는 같은 방식으로 다룹니다. 그림, 벡터 도형, 글 상자, 표, PDF 쪽, 슬라이드 요소 모두 선택·이동·크기·회전·투명도·순서·실행 취소가 똑같이 동작합니다. 파일 형식은 열 때와 저장할 때만 다릅니다.

원본을 깨뜨리지 않는 것이 원칙입니다. DOCX·HWPX·PPTX·XLSX·PDF는 고치지 않고 원래 형식으로 저장하면 원본 파일과 같은 바이트로 저장하고, 고친 경우에도 고친 곳만 다시 쓰는 것을 원칙으로 합니다(형식과 편집 종류에 따라 다를 수 있습니다). 다른 형식으로 옮길 때 잃는 내용이 있으면 미리 알려 줍니다.

열 수 있는 것
• 문서: DOCX, DOC, HWPX, HWP, Markdown, HTML, EPUB, 텍스트
• 표: XLSX, XLS, CSV
• 슬라이드: PPTX, PPT — 마스터, 전환, 애니메이션, 전체 화면 슬라이드쇼
• PDF: 쪽 보기, 글을 편집 가능한 개체로 바꾸기, 메모·형광펜, 양식, 암호 PDF
• 이미지: PNG, JPG, WebP, TIFF, PSD(레이어·조정 레이어·CMYK·16비트)
• 벡터: SVG, AI, 펜·도형·합치기/빼기
• 도면: DWG·DXF 가져오기 — 레이어·선 종류·글자

이미지 도구
• 업스케일: 고품질 보간 또는 AI 업스케일(사진·그림 자동 판별)
• 배경 지우기(누끼), 글자 인식(한국어·영어)
• AI 모델은 앱 안에 들어 있고 이 PC에서만 실행됩니다. 따로 내려받거나 서버로 보내지 않습니다.

빠른 도구: PDF 합치기, PDF 용량 줄이기, PDF→JPG, 이미지→PDF, 사진 용량 줄이기, JPG 일괄 변환 — 모두 이 PC에서 처리합니다.

암호 문서: PDF(AES-256), DOCX·XLSX·PPTX, .omw(AES-256-GCM)를 열고, 고친 뒤 다시 암호를 걸어 저장합니다.

작업 기록: 처음부터 모든 명령을 기록하고 어느 지점이든 미리 보고 되돌아갑니다. 비정상 종료 뒤에도 자동 저장에서 이어서 엽니다.

화면 언어: 한국어, English, 日本語, 简体中文

계정이 필요 없고 사용 기록을 어디에도 보내지 않습니다. 열고 고친 파일은 사용자가 고른 폴더에만 있습니다. Microsoft Store 판은 Store가 업데이트하므로 앱이 따로 업데이트를 확인하지 않습니다.

## 제품 기능 (Product features)
1. 이미지·벡터·PDF·문서·슬라이드·표·도면을 한 캔버스에서 편집
2. DOCX·HWPX·PPTX·XLSX·PDF·PSD를 원래 모양에 가깝게 열고, 고치지 않은 부분은 원본대로 저장하는 것이 원칙
3. 모든 개체에 같은 선택·이동·크기·투명도·순서·실행 취소
4. AI 업스케일·배경 지우기·글자 인식을 인터넷 없이 이 PC에서
5. PDF 합치기·용량 줄이기·변환 같은 빠른 도구
6. 암호 문서 열기와 다시 암호화해 저장
7. 작업 기록 타임라인과 자동 저장·복구
8. 계정 없음, 사용 기록 전송 없음, 한국어·영어·일본어·중국어(간체) 화면
