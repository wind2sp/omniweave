## Product name
Omniweave

## Short description
A local editor that opens and edits images, vector art, PDFs, DOCX and HWPX documents, slides, spreadsheets and DWG/DXF drawings on one canvas. Files are never uploaded, and the parts you did not change are kept as they were wherever the format allows. Free and open source.

## Description
Omniweave brings the work you used to spread across several programs onto one screen: fix the picture in a document, add text to a PDF, move it into a slide — on the same canvas.

Every object works the same way. Pictures, vector shapes, text boxes, tables, PDF pages and slide elements all share the same selection, moving, resizing, rotation, opacity, ordering and undo. File formats only matter when you open and save.

Your originals stay intact. For DOCX, HWPX, PPTX, XLSX and PDF, saving back to the original format without changes writes the same bytes as the original file, and an edit aims to rewrite only what changed (this depends on the format and the kind of edit). When moving to another format would lose something, Omniweave tells you first.

What it opens
• Documents: DOCX, DOC, HWPX, HWP, Markdown, HTML, EPUB, plain text
• Spreadsheets: XLSX, XLS, CSV
• Slides: PPTX, PPT — masters, transitions, animations, full-screen slide show
• PDF: page view, turn text into editable objects, comments and highlights, forms, password-protected PDFs
• Images: PNG, JPG, WebP, TIFF, PSD (layers, adjustment layers, CMYK, 16-bit)
• Vector: SVG, AI, pen, shapes, unite/subtract
• Drawings: DWG/DXF import — layers, linetypes, text

Image tools
• Upscaling: high-quality interpolation or AI upscaling (photo or artwork chosen automatically)
• Background removal and text recognition (Korean and English)
• The AI models are inside the app and run on this PC only. Nothing is downloaded or sent to a server.

Quick tools: merge PDFs, shrink PDFs, PDF to JPG, images to PDF, shrink photos, batch JPG conversion — all on this PC.

Password-protected files: open PDF (AES-256), DOCX/XLSX/PPTX and .omw (AES-256-GCM), edit, and save encrypted again.

History: every command since the start is recorded; preview any point and go back to it. After a crash, Omniweave reopens from its autosave.

Languages: 한국어, English, 日本語, 简体中文

No account is needed and no usage data is sent anywhere. The files you open and edit stay in the folders you choose. The Microsoft Store version is updated by the Store, so the app does not check for updates itself.

Free and open source (GPL-3.0-or-later). Source code: https://github.com/wind2sp/omniweave

This is an early version. Keep a copy of important originals. If a file does not open correctly, please tell us on GitHub Issues.
