# OMNIWEAVE 상표 출원 — 최종 견본

**업로드할 파일: `OMNIWEAVE_trademark_specimen.jpg`**

| 항목 | 값 |
|---|---|
| 상표 유형 | 일반상표 (평면 결합상표: 도형 + 영문 + 한글) |
| 색채 | 흑백 (색채 지정 없음 → 어떤 색으로 써도 보호) |
| 견본 규격 | 945×945px = 8cm×8cm @ 300dpi |
| 파일 형식 | 표준(baseline) JPEG, RGB, 흰 배경, 투명도 없음 — 생성 시 자동 검사 통과 |
| 파일 크기 | 약 76KB |
| 상표 명칭(출원서 기재 예) | OMNIWEAVE 옴니위브 |
| 지정상품·서비스업(권장) | 제9류 내려받기 가능한 컴퓨터 소프트웨어 등 / 제42류 SaaS·소프트웨어 설계·개발 등 — 세부 명칭은 변리사와 확정 |

## 이 시안을 고른 이유

1. **한 건으로 세 가지를 지킵니다** — 로고 도형, 영문 이름(OMNIWEAVE), 한국어 읽는 법(옴니위브).
2. **흑백**이라 브랜드 색을 바꿔도 등록 효력이 그대로입니다(컬러로 등록하면 그 색 조합에 묶일 수 있음).
3. **오래 쓸 모양**입니다 — 앱 아이콘·홈페이지·SNS가 모두 같은 "세 가닥 실 + 2×2 타일" 도형을 씁니다(`assets/make_icon.py`).
   앞으로 색과 질감은 바꿔도 이 도형의 뼈대는 유지하세요. 도형을 크게 바꾸면 새로 출원해야 할 수 있습니다.
4. **작게 인쇄돼도 읽힙니다** — 공보 인쇄 크기(약 1.5~2cm)로 줄여서 확인했습니다(`check_small_sizes.png`).
   시안 07 대비 실 사이 흰 틈과 가운데 타일을 굵게 다듬었습니다.

## 함께 고려할 것

- 결합상표는 전체를 하나로 보고 심사하므로, 로고 없이 **글자 "OMNIWEAVE"만** 쓰는 모방을 막는 힘은 문자상표보다 약할 수 있습니다.
  예산이 되면 `../01_wordmark_OMNIWEAVE.jpg`를 별도 출원(문자상표)하는 것이 가장 튼튼합니다.
- 출원 전 KIPRIS에서 "OMNIWEAVE", "옴니위브", 비슷한 발음(옴니웨이브 등) 선행 상표를 확인하세요.
- 등록 전 표기는 Omniweave™, 등록 후에는 Omniweave®.

다시 만들기: `python assets/trademark/make_trademark.py` (모든 견본 + 최종본 + 검사)
