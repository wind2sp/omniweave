# 실무 샘플 파일 (저장소에 올리지 않음)

이 폴더의 파일은 `.gitignore`로 제외되어 GitHub에 올라가지 않습니다. 이 PC에서 가져오기 테스트에만 씁니다.

| 폴더 | 넣을 파일 |
|---|---|
| `hwpx/` | 한글 `.hwpx` (공문서, 표가 많은 문서 등). 구형 `.hwp`도 넣어 주시면 미지원 판정용으로 씁니다 |
| `docx/` | Word `.docx` (보고서, 서식 많은 문서) |
| `pdf/`  | 텍스트 PDF, 스캔 PDF |
| `pptx/` | PowerPoint `.pptx` (가져오기 구현 대상 판단용) |
| `images/` | PNG·JPG·SVG, 포토샵/일러스트에서 내보낸 파일. `.psd`·`.ai` 원본도 판정용으로 환영 |
| `etc/` | 그 밖에 오메로 열어 보고 싶은 파일 |

개인정보·기밀이 들어 있는 파일은 넣지 마세요.
