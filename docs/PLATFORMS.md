# 앱 · 웹 · 설치 프로그램 — 하나의 오메

오메는 처음부터 **하나의 코드베이스**(TypeScript 엔진 + React UI + Tauri 2 셸)로 만들어서, 같은 엔진이 세 곳에서 돕니다.
어디서 열어도 같은 `.omw` 파일, 같은 Loom 엔진, 같은 원본 보존 규칙을 씁니다.

| | 설치 프로그램 (Windows·macOS·Linux) | 웹 (브라우저) | 모바일 앱 (Android·iOS) |
|---|---|---|---|
| 상태 | ✅ Windows 설치본·포터블, 자동 업데이트 / macOS·Linux 실험적 | ✅ 빌드 준비 완료(`/app/` 데모, 공개 시 노출) | 🧪 기획 — 이 문서 |
| 역할 | 본격 편집(6-in-1 전체) | 설치 없이 바로 써 보기·간단 편집·빠른 도구 | 이동 중 보기·간단 편집·빠른 도구·스캔·서명 |
| 파일 | 로컬 파일 | 브라우저 파일 선택·다운로드 | 휴대폰 저장소·공유 시트·클라우드 앱 |
| 처리 위치 | 이 컴퓨터 | 이 브라우저(업로드 없음) | 이 휴대폰(업로드 없음) |
| 배포 | GitHub Releases | GitHub Pages | Google Play · App Store (무료) |

## 무료 모바일 앱 기획

### 왜 모바일인가
- 사람들은 PDF·문서를 **휴대폰으로 받습니다**(메신저·메일). 열고, 서명하고, 합치고, 용량 줄여서 다시 보내는 일이 대부분 휴대폰에서 일어납니다.
- 이런 앱 대부분이 **업로드 방식이거나 광고·구독**입니다. "완전 무료 · 광고 없음 · 업로드 없음 · 원본 보존"은 모바일에서 더 강한 차별점입니다.

### 1단계 — 보기 + 빠른 도구 (모바일 MVP)
- 열기: PDF, DOCX, HWPX, PPTX, XLSX, 이미지, `.omw` — 데스크톱과 같은 가져오기 엔진
- 보기: 페이지 넘기기, 핀치 확대, 슬라이드쇼, 검색
- 빠른 도구(이미 있는 `src/io/tools` 재사용): PDF 합치기·용량 줄이기·JPG 변환, 이미지→PDF, 사진 용량 줄이기, JPG 변환
- **공유 시트 연동**: 메신저에서 받은 파일 → "오메로 열기", 결과 → 바로 공유
- 암호 문서 열기·재암호화(데스크톱과 같은 보안 모듈)

### 2단계 — 모바일에 맞는 간단 편집
- PDF 텍스트 고치기(PDF 엔진), 주석·형광펜·손글씨(펜·손가락, 압력 지원)
- **서명**: 손글씨 서명 저장 → 문서에 붙이기
- **문서 스캔**: 카메라로 촬영 → 자동 자르기·보정 → PDF
- 슬라이드·문서의 글자 고치기, 사진 자르기·회전·밝기

### 3단계 — 기기 사이 이어 하기
- 같은 `.omw`를 휴대폰과 PC에서 이어서 편집. Loom의 **내용 주소 조각** 덕분에 동기화할 때 **바뀐 조각만** 주고받습니다(파일 전체 아님).
- 동기화 통로는 사용자가 고르는 저장소(휴대폰-PC 직접 연결, 사용자의 클라우드 폴더)로 — 오메 서버를 두지 않습니다.
- 작업 히스토리도 함께 이어집니다.

### UI 원칙
- 데스크톱 UI를 줄인 것이 아니라 **터치 전용 화면**: 아래쪽 도구 막대, 상황에 따라 바뀌는 시트, 한 손 조작.
- 화면 폭에 따라 자동 전환: 휴대폰(보기·간단 편집) / 태블릿(데스크톱에 가까운 편집, 펜 지원).
- 같은 엔진·같은 파일 형식 — 모바일에서 저장한 파일은 PC에서 그대로 열립니다.

## 기술 방식
- **Tauri 2 모바일**(Android·iOS)로 지금 코드를 그대로 씁니다. 파일 접근·공유 시트·카메라는 Tauri 플러그인(필요하면 작은 네이티브 플러그인 추가).
- 무거운 처리(PDF 압축, 대용량 파일)는 웹 워커로 옮겨 화면이 멈추지 않게 합니다.
- 메모리: 휴대폰은 메모리가 작으므로 Loom 타일 캐시 상한을 기기에 맞게 낮추고, 큰 파일은 필요한 페이지만 풀어 씁니다.
- 테스트: 데스크톱과 같은 테스트 + 실제 기기 확인(Android는 이 PC의 에뮬레이터, iOS는 macOS CI).

## 준비가 필요한 것 (결정·비용)
| 항목 | 내용 |
|---|---|
| Google Play 개발자 계정 | 1회 등록비(약 25달러). 법인 명의 가능 |
| Apple Developer Program | 연회비(약 99달러). **iOS 빌드에는 macOS가 필요** → GitHub Actions의 macOS 빌드 머신으로 해결 가능 |
| Android 빌드 도구 | 이 PC에 Android Studio·SDK·NDK 설치 필요(수 GB) |
| 개인정보 처리방침 | 스토어 등록 필수 — "수집하는 정보 없음"으로 작성 |
| 상표 | 앱 이름 "Omniweave"는 상표 출원과 같은 이름 사용 |
